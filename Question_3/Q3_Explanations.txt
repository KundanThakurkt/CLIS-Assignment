Question 3
Please refer screenshots Question3_part1.png and Question3_part2.png, sample_data.txt and sample_hard.txt files for command execution and output with below explanations:

1. File Creation
Command: echo "This is some sample data for link testing." > ~/sample_data.txt
Output: [sample_data.txt is created with given sample text.]
Explanation: The echo command creates a file named sample_data.txt in the home directory and writes sample text into it using output redirection.

Command: cat sample_data.txt
Output: This is some sample data for link testing
Explanation: The cat command displays the content of the file sample_data.txt

2. Hard Link Creation
Command: ln sample_data.txt sample_hard.txt
Output: [hard link is created with sample_hard.txt]
Explanation: The ln command creates a hard link named sample_hard.txt that points to the same inode as sample_data.txt

3. Symbolic Link Creation
Command: ln -s sample_data.txt sample_soft.txt
Output: [symbolic (soft) link to sample_data.txt named sample_soft.txt is created]
Explanation: The ln -s command creates a symbolic link named sample_soft.txt that stores the path to sample_data.txt.

4. Inode Verification
Command: ls -li sample_data.txt sample_hard.txt sample_soft.txt
Output: [Shows inode numbers, file permissions, users, groups, and timestamps, refer Question3_part1.png]
Explanation: The ls -li command displays inode numbers along with file details, allowing comparison between the original file and its links.

5. Inode Analysis [Refer Question3_part1.png]
Explanation: sample_data.txt and sample_hard.txt share the same inode number <1048711> because hard links reference the same inode.
             sample_soft.txt has a different inode <1048709> because symbolic links store a path, not the actual inode.

6. File Metadata Inspection
Command: stat sample_data.txt
Output: [Full stat output, refer Question3_part1.png]
Explanation: The stat command displays detailed metadata including permissions, ownership, file size, and access, modify, and change timestamps.

7. Disk Usage Check
Command: du -sh ~
Output:  2.6G /root
Explanation: The du -sh command displays the total disk usage of the home directory in a summarized and human-readable format.

8. File Size Overview
Command: ls -lh ~
Output:  [Displays file sizes, permissions, users, groups and timestamps of directories and files, refer Question3_part1.png]
Explanation: The ls -lh command lists files in the home directory along with their sizes in a human-readable format.

9. Link Deletion Test
Command: rm sample_soft.txt
         ls sample_data.txt
Output:  [Removal of symbolic link with rm, and with ls displaying unaffected sample_data.txt, refer Question3_part2.png]
Explanation: The symbolic link sample_soft.txt is deleted using rm, while the original file remains unaffected because symlinks do not own the inode.

10. Disk Utility Demonstration
Command: du -h sample_data.txt
Output:  4.0K sample_data.txt
Explanation: The du -h command shows the disk space used by a specific file or directory.

Command: df -h
Output:  [The output shows disk and memory filesystems, their total size, used space, free space, and where they are mounted, with /dev/sda1 being the main real disk. Refer Question3_part2.png]
Explanation: The df -h command displays filesystem-level disk usage, including total, used, and available space.
