# CLIS-Assignment

This repository contains the complete submission for the Command Line Interfaces and Scripting Lab Assignment.

All tasks were performed using my own user account without making any system configuration changes.  
Each question has been organized into a separate folder as instructed.

---

## Repository Structure

.
├── Question_1/
├── Question_2/
├── Question_3/
├── Question_4/
└── README.md


Each **Question folder** contains:
- Commands executed during the task
- Corresponding command outputs
- Screenshots of command execution/output
- Files created as part of the task
- An `Q[n]_Explanations.txt` file with **1–2 sentence explanations after every command**

---

## Question Overview

### Question 1 – User & Environment Verification
- User identity and group verification
- Workspace validation
- File creation and integrity checks
- System, network, and uptime verification

### Question 2 – File & Directory Management
- Directory and file creation
- File content management
- File duplication and movement
- Recursive directory listing and path verification

### Question 3 – Links & Disk Usage
- Hard and symbolic link creation
- Inode verification and analysis
- File metadata inspection
- Disk usage and filesystem utilities

### Question 4 – Process & System Monitoring
- Uptime and process analysis
- CPU and memory usage monitoring
- Background process handling
- Disk usage visualization using `ncdu`
